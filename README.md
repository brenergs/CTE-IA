## 📌 Sobre o Programa

Este repositório reúne todos os códigos, estudos de caso, exercícios práticos, entregas semanais e projetos desenvolvidos por **Brener Gomes dos Santos** durante a fase teórica da **Residência em TIC 44 — Capacitação Técnica e Empreendedora em Inteligência Artificial (CTE-IA)**.

A residência tecnológica tem como objetivo formar e aprofundar especialistas de alto nível em Inteligência Artificial e Ciência de Dados, combinando rigor acadêmico, experimentação prática e visão de impacto em negócios.

### 🏛️ Realização e Apoio
* **Instituições Executoras:** [Universidade Federal do Ceará (UFC)](https://www.ufc.br/) & [Fundação para o Desenvolvimento Tecnológico da Engenharia (FDTE)](https://www.fdte.org.br/)
* **Iniciativa e Fomento:** Programa **MCTI Futuro** ([Ministério da Ciência, Tecnologia e Inovação - MCTI](https://www.gov.br/mcti)), no âmbito do **PPI SOFTEX**
* **Parceiro Tecnológico:** [SiDi (Intelligence & Innovation Center)](https://www.sidi.org.br/)

## 📚 Estrutura Curricular & Módulos

O programa é composto por 8 módulos sequenciais e complementares, totalizando mais de 50 notebooks de implementações práticas:

| # | Módulo | Descrição & Principais Tópicos | Pasta |
|:---:|:---|:---|:---:|
| **01** | **Programação para Ciência de Dados** | Fundamentos da linguagem Python para dados, manipulação com Pandas e NumPy, vetorização, estruturas de dados e projeto integrador base. | [`Programação para Ciência de Dados`](./Programação%20para%20Ciência%20de%20Dados/) |
| **02** | **Fundamentos de Mineração de Dados** | Pré-processamento, limpeza, tratamento de valores faltantes/outliers, análise exploratória (EDA), regras de associação e visualização de dados. | [`Fundamentos de Mineração de Dados`](./Fundamentos%20de%20Mineração%20de%20Dados/) |
| **03** | **Estatística Aplicada a Negócios** | Probabilidade, inferência estatística, distribuições, testes de hipóteses, correlação, regressão e tomada de decisão orientada a dados. | [`Estatística Aplicada a Negócios`](./Estatística%20Aplicada%20a%20Negócios/) |
| **04** | **Aprendizagem de Máquina** | Algoritmos supervisionados e não-supervisionados (árvores, regressão, classificação, clustering com k-means/DBSCAN), validação cruzada e métricas de desempenho. | [`Aprendizagem de Máquina`](./Aprendizagem%20de%20Máquina/) |
| **05** | **Tópicos Avançados em ML** | Redes neurais profundas, aprendizado por reforço (*Gymnasium*), streaming/online machine learning (*River*), ensemble methods e otimização. | [`Tópicos Avançados em Aprendizagem de Máquina`](./Tópicos%20Avançados%20em%20Aprendizagem%20de%20Máquina/) |
| **06** | **Processamento de Linguagem Natural (PLN)** | Tokenização, embeddings (Word2Vec, GloVe), modelos de linguagem, transformers (*Hugging Face*), análise de sentimentos e construção de chatbot com interface interativa (*Gradio*). | [`Processamento de Linguagem Natural`](./Processamento%20de%20Linguagem%20Natural/) |
| **07** | **Processamento de Imagem e Visão Computacional** | Filtros espaciais, segmentação, morfologia matemática, detecção e extração de características com OpenCV e modelos de detecção de objetos (YOLO / *Ultralytics*). | [`Processamento de Imagem e Visão Computacional`](./Processamento%20de%20Imagem%20e%20Visão%20Computacional/) |
| **08** | **IA Aplicada aos Negócios** | Estratégia de dados, identificação de dores de negócio, métricas de ROI, prototipação de soluções inteligentes e apresentação executiva de modelos. | [`Inteligência Artificial Aplicada a Negócios`](./Inteligência%20Artificial%20Aplicada%20a%20Negócios/) |

## 💡 Destaques de Projetos & Aplicações

- 🤖 **Chatbot Inteligente com PLN & Gradio:** Construção de pipeline de processamento textual, extração semântica e interface conversacional integrada.
- 👁️ **Visão Computacional & Detecção com YOLO:** Classificação de imagens e detecção de objetos em tempo real utilizando PyTorch, Torchvision, OpenCV e Ultralytics.
- ⚡ **Machine Learning Contínuo & Streaming:** Aplicação de algoritmos de aprendizado incremental para fluxos de dados contínuos com a biblioteca *River*.
- 🎮 **Aprendizado por Reforço:** Modelagem de agentes e ambientes de tomada de decisão com *Gymnasium*.
- 📊 **Análises Estatísticas e Modelagem de Negócios:** Estudos aplicados para previsão de tendências, segmentação e otimização de decisões comerciais.

## 🚀 Como Executar

### 1. Clonar o Repositório
```bash
git clone https://github.com/brenergs/CTE-IA.git
cd CTE-IA
```

### 2. Criar e Ativar um Ambiente Virtual
```bash
# Criar ambiente virtual
python -m venv venv

# No Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# No Linux / macOS:
source venv/bin/activate
```

### 3. Instalar Dependências Principais
```bash
pip install numpy pandas scikit-learn matplotlib seaborn torch torchvision opencv-python transformers nltk spacy gradio
```

### 4. Executar o Jupyter Lab / Notebook
```bash
jupyter lab
# ou
jupyter notebook
```
Navegue pelas pastas dos módulos para inspecionar os notebooks e reproduzir os experimentos.
